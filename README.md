# Telecom Customer Churn Analysis

## Project Overview
Analyzed telecom customer data to understand customer churn and identify patterns related to customer behavior, services, and billing.

## Problem Statement
To understand why customers leave a telecom service by analyzing customer demographics, services, contract details, and billing information.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Power BI

## Python — EDA
- Performed basic data exploration and statistical analysis.
- Checked data types, missing values, and duplicate records.
- Cleaned and prepared the dataset for analysis.
- Analyzed customer demographics, services, contracts, and billing details.
- Used visualizations to explore customer churn patterns.

## SQL Analysis
- Used SQL to analyze customer churn data.
- Applied filtering, grouping, sorting, and aggregate functions.
- Analyzed churn based on contract type, internet service, payment method, tenure, and other customer attributes.

## Power BI Dashboard
- Created a simple interactive dashboard.
- Used KPI cards to display customer and churn metrics.
- Added visuals to analyze customer churn patterns.
- Added slicers to filter and explore customer data.

## Key Insights
- Identified patterns between customer churn and different customer attributes.
- Compared churn across contract and service categories.
- Analyzed customer tenure and billing patterns in relation to churn.
